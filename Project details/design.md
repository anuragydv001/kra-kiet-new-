# Design System

## 1. Color Palette
- **Primary (Brand):** Deep Blue (`#1E3A8A` / Tailwind `blue-900`) - Used for headers, primary buttons.
- **Secondary:** Slate (`#475569` / Tailwind `slate-600`) - Used for secondary text and borders.
- **Background:** Light Gray (`#F8FAFC` / Tailwind `slate-50`) - Main application background.
- **Accent/Success:** Emerald (`#10B981` / Tailwind `emerald-500`) - For "Approved" or "Target Met" badges.
- **Warning:** Amber (`#F59E0B` / Tailwind `amber-500`) - For "Pending" or "In Review".
- **Danger:** Rose (`#E11D48` / Tailwind `rose-600`) - For missed deadlines or errors.

## 2. Typography
- **Primary Font:** Inter (or system sans-serif).
- **Headings:** Bold, dark blue, tightly spaced.
- **Data Tables:** Monospaced numbers for tabular data (achievements/targets) to ensure decimal alignment.

## 3. UI Components
- **Forms:** Clean, bordered inputs with subtle focus rings (`ring-blue-500`).
- **Cards:** Slight shadow (`shadow-sm`), rounded corners (`rounded-lg`), white background.
- **Layout:** Fixed sidebar navigation for Super Admins/HODs, top app bar for user profile/logout.
